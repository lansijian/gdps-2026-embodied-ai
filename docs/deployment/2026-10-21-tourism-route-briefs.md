# 文旅导览 P3 沿途讲解分段表（草稿，待现场确认）

对应赛题 P3：导览过程中结合空间上下文自动触发沿途讲解（经过钟楼讲建筑历史、经过文创店讲特色商品）。
实现：`TourFlow.on_route_exhibit()` / `station.route_match_exhibit_ids` + `route_brief`，
同一地标只讲一次、两次简讲间隔 ≥ `brief_gap_s`（默认 20s），单句 ≤ 25 字、播报 ≤ 6s。

## 触发方式（优先级从高到低）

1. **视觉匹配**：行进中每 `--scan-interval` 秒识别一次，命中站点的 `route_match_exhibit_ids` 就播 `route_brief`；
2. **地图标注辅助（待实现）**：视觉漏检时，按导航距离到站点 < 1.5m 触发同一句话；
3. **人工/主控**：可发 `/tourism/visual_target` 手动补一条。

## 内容准则

- 沿途只回答"这是什么/在哪"，历史故事留到停留点长讲解时再讲，避免"到了下一点还在讲上一个"；
- 不打断游客提问：`brief_gap_s` 内不重复、同一地标不重复；正在长讲解时不插入（状态门控在 `on_landmark`）；
- 与 P2 冲突：游客点播目标优先，点播导航途中不播无关简讲（当前由状态机保证：只有 NAVIGATING 且同一站点未讲过才播）；
- 所有简讲文案需要馆方审核后再上真机（现在为占位）。
